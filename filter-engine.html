WARSTWA DOKUMENTOWA

Filter Engine

Wspólna warstwa przygotowania i rekonstrukcji dokumentów. Nie jest backendem tłumaczeniowym.

FORMATY NIETEKSTOWE

Najpierw struktura, potem tłumaczenie

Filter Engine dekoduje format dokumentowy, wydobywa tekst do tłumaczenia i po odpowiedzi backendu rekonstruuje dokument.

Dotyczy to DOCX, ODT, HTML/XHTML, EPUB i XLIFF 2.0.

Przepływ:
plik → Filter Engine → tekst → wybrany backend → przetłumaczony tekst → Filter Engine → plik wynikowy

FORMATY TEKSTOWE

TXT, Markdown i przyszłe formaty tekstowe omijają filtry

Format natywnie tekstowy trafia bezpośrednio do wybranego backendu. Nie uruchamiamy filtra dokumentowego.

Zasada:
TXT → tekst → backend → tekst
MD → tekst → backend → tekst

Tak samo będą obsługiwane przyszłe formaty tekstowe.

Robi

Dekoduje strukturę dokumentu, przekazuje jednostki tekstowe i rekonstruuje dokument.

Nie robi

Nie jest backendem i nie zastępuje llama.cpp, Cloud, Apertium ani Własnego serwera.

Nie dotyczy tekstu

Formaty tekstowe omijają filtry.
