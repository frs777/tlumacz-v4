BACKEND · WŁASNA USŁUGA

Własny serwer

Backend custom pozwalający wskazać zewnętrzny serwer tłumaczeniowy zgodny z wymaganym API.

KONFIGURACJA

Własny endpoint

Użytkownik podaje adres serwera i dane uwierzytelniające zgodnie z konfiguracją usługi. Backend ma własne parametry endpointu, klucza i modelu.

  • adres / base URL serwera
  • endpoint API
  • klucz API, jeśli serwer go wymaga
  • nazwa modelu
  • parametry żądania zgodne z usługą
  • timeout i obsługa błędów
Istotne rozróżnienie:
„Własny serwer” jest osobnym backendem w rejestrze aplikacji, ale jego transport wykorzystuje CloudRouter. Nie jest to lokalny runtime zarządzany przez aplikację.

Serwer

Serwer działa poza aplikacją. Tłumacz wskazuje jego adres i wysyła żądania zgodnie z kontraktem.

Model

Nazwa modelu jest parametrem wskazywanym dla usługi. Aplikacja nie zarządza procesem modelu po stronie zewnętrznego serwera.

Bezpieczeństwo

Klucze i tokeny nie powinny trafiać do dokumentacji ani repozytorium. W konfiguracji V4 wykorzystywany jest magazyn sekretów.

Kontrakt API: szczegóły request/response zależą od zgodności wskazanego serwera z kontraktem obsługiwanym przez CloudRouter. Strona nie deklaruje kompatybilności z dowolnym API tylko dlatego, że jest ono dostępne przez HTTP.
