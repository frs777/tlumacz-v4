Apertium

Oddzielny backend oparty na lokalnym runtime Apertium i zainstalowanych danych językowych.

KONFIGURACJA

Para językowa i runtime

Backend wykrywa dostępne pakiety przez dane runtime, mapuje kody ISO na kody Apertium i buduje kierunkową parę, np. eng-pol.

  • wykrywanie pakietów językowych
  • mapowanie ISO ↔ kod Apertium
  • wybór dostępnej pary językowej
  • limity czasu, wejścia i wyjścia
  • health-check
  • diagnostyka procesu
Runtime:
W dystrybucji V4 runtime Apertium jest dostarczany osobno od danych językowych. Konkretna para jest dostępna tylko wtedy, gdy odpowiednie dane są zainstalowane.

WAŻNE

Gotowość pary jest niezależnym kryterium

Samo wykrycie pakietu nie oznacza, że każda para jest gotowa produkcyjnie. Aktualny stan wydania wskazuje eng-pol/cas_sp jako blocker finalnego release.

Planowane: wybrane pary językowe Apertium mogą w przyszłości być udostępniane przez portal projektu/vhost. Nie jest to obecnie działająca usługa.
