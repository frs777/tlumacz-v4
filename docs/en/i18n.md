# Documentation localization — Tłumacz V4

The project uses Polish as the canonical source language and maintains English and German localization layers.

## Application localization

The QML GUI localization is implemented in:
- src/tlumacz/i18n.py — central PL/EN/DE translation catalog;
- src/tlumacz/qml_gui/bridge.py — QML localization bridge and help loading;
- src/tlumacz/qml_gui/Main.qml, TranslationPage.qml, ApiPage.qml, ExtrasPage.qml, HelpPage.qml — localized GUI surface;
- src/tlumacz/qml_gui/help.pl.md, help.en.md, help.de.md — user help;
- src/tlumacz/qml_gui/config.py — persistent language setting.

The application language can be changed from the Help tab without restarting the application.

## Synchronization

Polish is the source of truth. English and German translations must preserve technical identifiers, paths, commands, class names, configuration values and test results.

## Current scope

The active QML interface, user help, user-visible log labels and localization governance documents are localized in PL/EN/DE. Historical research, evidence logs and selected plans remain explicitly tracked rather than being presented as fully localized.

See docs/I18N_STATUS.md for the current translation register.
